## Activation checklist

- Confirm residence and actual bank-account country with the owner.
- Owner completes identity, banking and tax information directly in GitHub/payment-provider forms.
- Save and review bilingual profile copy and voluntary tiers.
- Submit enrollment/profile for GitHub review when the form is complete.
- Verify the public profile is active before adding `github: deimisq` to `.github/FUNDING.yml` or linking donations from the app.
- Reuse the same approved profile in other repositories; individual repositories can each link to the creator's Sponsors account.
