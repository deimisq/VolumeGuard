# Support the project / Apoya el proyecto

VolumeGuard is free and open-source software. If it helps you, you may support its creator through a voluntary contribution to maintain and improve the project. All features remain available without donating.

VolumeGuard es gratuito y de código abierto. Si te resulta útil, puedes apoyar a su creador con un aporte voluntario para ayudar a mantener y mejorar el proyecto. Todas las funciones están disponibles sin donar.

## GitHub Sponsors

**[Apoyar a deimisq / Sponsor deimisq](https://github.com/sponsors/deimisq)**

El perfil de GitHub Sponsors está activo. Los aportes apoyan el trabajo de código abierto de deimisq, incluido VolumeGuard y sus otros proyectos. Puedes elegir entre las opciones que ofrece el perfil. Aportar es voluntario: no compra funciones, soporte prioritario ni compromisos de entrega.

The GitHub Sponsors profile is active. Contributions support deimisq's open-source work, including VolumeGuard and other projects. Choose from the options offered on the profile. Sponsorship is voluntary and does not purchase features, priority support or delivery commitments.

El pago se realiza en GitHub, fuera de la app. VolumeGuard no solicita ni procesa datos bancarios o de tarjeta. / Payments take place on GitHub, outside the app. VolumeGuard does not request or process bank or card information.
