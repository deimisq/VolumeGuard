# Security / Seguridad

VolumeGuard runs a privileged Windows service in its administrative edition. Report vulnerabilities privately to the maintainer through GitHub's private vulnerability reporting feature if enabled. If it is unavailable, open an issue requesting a private contact without disclosing exploit details or secrets. A dedicated contact will be added when the maintainer supplies one.

Do not publish passwords, signing keys or sensitive logs in an issue. Include the affected version, impact and a minimal reproduction in the private report. There is currently no guaranteed response time or formal supported-version policy.

Para vulnerabilidades, utiliza el reporte privado de GitHub si está habilitado. Si no está disponible, solicita un contacto privado mediante una incidencia sin detalles de explotación. No incluyas secretos ni registros con datos personales. Aún no existe un plazo garantizado de respuesta.
